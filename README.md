  # Кредитный скоринг в условиях экстремального дисбаланса классов (Credit Scoring)

**Проект посвящен разработке сквозного пайплайна кредитного скоринга для бинарной классификации заемщиков (определение риска дефолта)**. Ключевая особенность данных — экстремальный дисбаланс классов (целевой класс `MARKER` составляет всего `0.38%`). В рамках исследования построена и оптимизирована модель градиентного бустинга CatBoost, обеспечивающая экономически обоснованный баланс рисков для банковского бизнеса.

## 🔍 Ключевые этапы реализации проекта

### 1. Разведочный анализ данных (EDA)
* **Размер выборки**: Train — 91 528 строк, Test — 38 405 строк, 26 признаков.
* **Очистка текста**: Категориальные признаки (14 колонок) приведены к нижнему регистру, удалены лишние пробелы.
* **Анализ пропусков**: Выявлены аномалии в признаках Z (50% пропусков), H (~15%) и L (~9%).
* **Сигнал в пропусках**: Объекты с пропусками в признаках U, W, E, Z имеют повышенную частоту дефолта.

### 2. Предобработка данных (Pipelines)
Пайплайн предобработки адаптирован под специфику каждой архитектуры:
* **Для линейных моделей и RF**: Пропуски чисел заполнялись медианой (из-за выбросов) с генерацией бинарных индикаторов пропуска (`add_indicator=True`). Применено One-Hot кодирование и устойчивое масштабирование `RobustScaler`.
* **Для CatBoost**: Числовые пропуски оставлены в сыром виде (`passthrough`). Алгоритм самостоятельно определял оптимальное ветвление для значений NaN.
* **Общее**: Пропуски в категориях выделены в отдельный класс `unknown`.

### 3. Выбор порога классификации: Бизнес vs Математика
* Формальная оптимизация по F1-кривой предложила математический порог `0.929`.
* Порог `0.929` поднял Precision до 15.2%, но обрушил Recall до `8.2%` (пропуск 91.8% дефолтов).
* **Бизнес-решение**: Оставлен стандартный порог `0.5`. В банковском скоринге цена пропуска дефолта (False Negative) кратно превышает цену ложного отказа (False Positive).

### 4. Интерпретация модели (SHAP & Feature Importance)
Топ-3 ключевых драйверов модели: `L` (12.01%), `G` (10.31%), `J` (8.11%).
* **Факторы стабильности** (например, лидер важности `L`) снижают риск дефолта (отрицательный SHAP-эффект).
* **Факторы активности и финансовой нагрузки** (например, `G` и `N`) линейно увеличивают риск.

Построенная модель **CatBoost (RandomizedSearchCV)** обеспечивает экономически обоснованное внедрение в продакшн. Она успешно находит **71.2%** дефолтных заемщиков на абсолютно новых данных, минимизируя прямые финансовые потери финансовой организации.
